UX review: the whole application

Before is the original design, after is the final state. 73 screens in two apps, reviewed and rebuilt on shared foundations. The index with every finding, decision and what is left is in AUDIT.md; the conventions are in COMPONENTS.md.

Navigation and shared system

Settings: 14 tabs become 4 groups

The old strip clipped and every Settings page was titled "Settings". Navigation is now defined once; each page carries its own name, with a quiet second row for the pages in the group. Filter groups are labelled and row actions are one bordered button plus quiet ones.

Counter approvals: one action hierarchy

Four loud green buttons and two unlabelled chip rows became one labelled filter band, outlined row actions and a quiet second action.

Location view: a bug and a calmer table

Today and This week were shown together with neither selected, so each outlet appeared twice. It now defaults to Today.

Accounts

Overview: from a dashboard to a to-do list

The same facts appeared three times. Now: one contextual primary action, only unfinished work, one figures card.

Journals: attention first

Items waiting for approval come first; history is quiet; the whole row opens the journal.

Payments: show what needs follow-up

Four tiles and three filter rows became one banner and a default "Needs attention" view.

Bank reconciliation

One status banner replaces four tiles and a repeated calculation.

Chart of accounts

29 "Ledger" buttons that all opened the bank account are gone: the row opens its own account.

Settings and forms

Payment provider

The one real setting was buried under a reference card and three provider cards. Now one card; reference and other providers collapse.

Cash point accounts

Payment counters left the settings page, the red inline confirmation became the shared dialog, and row actions are quiet.

Add location: validation

Before: one error at a time and typed choices. After: every error under its field, a count, chips for State and Type.

Operations and "Your work"

Production

Sibling pages are tabs instead of header buttons; per-field errors; quiet Remove.

Purchasing

Tabs, a shared header, and the new request is a drawer instead of replacing the page.

Inventory

Tabs replace header buttons; counting is a dialog; empty and filter states are explained.

Approvals

Four green Review buttons became one outlined action per row; the drawer has a single primary.

Notifications

Mark-as-read is a quiet action; no competing header buttons.

Cash Point

Sale screen: one toolbar

Seven buttons in a row (and a different set on each sale screen) became Held sales, Cash out, Today's sales and a "Shift and staff" menu.

Close shift: steps in order

Cash, stock, held sales, then close, with a disabled Close that says what is missing. Stock counts can now be entered.

Today's sales

The whole row opens the receipt; Void is quiet.

Held sales

Explanation behind a disclosure; Recall is the only bordered action; Discard can be undone.

Users and password reset

The reset drawer rendered in the browser default serif font; the row is the control.

On a phone

Pages had no viewport tag, so phones showed a shrunken desktop layout. Lists now reflow into cards and the actions stay in view.
